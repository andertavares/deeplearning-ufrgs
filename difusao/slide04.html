O que é 256×256?

É a resolução espacial do mapa de ativações naquele nível — começa igual ao tamanho da imagem de entrada. A cada Pool↓, cai pela metade: 256 → 128 → 64 → 32 → 16.

🎛️
O que é 64ch?

Sim — são 64 filtros convolucionais. Cada filtro detecta um padrão diferente (bordas, texturas…). O encoder dobra os canais a cada nível enquanto reduz a resolução: 64 → 128 → 256 → 512 → 1024ch.

🗜️
Compressão do Gargalo

Entrada: 256×256×3 = 196.608 valores. Gargalo: 16×16×1024 = 262.144 valores. Surpresa: o tensor do gargalo é maior em valores brutos! A compressão é espacial — cada célula 16×16 precisa capturar o contexto de uma região 16×16 da entrada.

🔄
Pool↓ vs Up↑ — Opostos

Pool↓ (max/avg pooling) descarta pixels, reduzindo a resolução pela metade — operação sem pesos.
UpConv (convolução transposta) faz o inverso: aprende a expandir, dobrando a resolução. Tem pesos treináveis — é como uma "deconvolução".

🔤 O formato do diagrama lembra um U — daí o nome. É um autoencoder com atalhos (skip connections) entre os dois lados.
