🚀 Inferência: Passo a Passo
①
Ponto de partida: ruído puro

Não há imagem inicial. Amostra-se xT ~ 𝒩(0, I) — puro ruído gaussiano sem estrutura alguma. Este "caos" é a semente de toda geração.

②
U-Net prevê e subtrai o ruído

A cada passo t (de T até 1), a U-Net recebe xt e o tempo t, estima o ruído ε̂ presente, e o subtrai parcialmente: xt−1 = (xt − ε̂ · fator) + pequena amostragem aleatória.

③
~1000 passos: a imagem emerge

Após ~1000 iterações, x0 é uma imagem coerente e detalhada. Cada passo remove um pouco do caos — como um escultor retirando uma lasca de mármore de cada vez.

④
Novo início = nova imagem

Amostrar um xT diferente gera uma imagem completamente diferente. A diversidade vem do ruído inicial — não de uma entrada controlada pelo usuário.

🔄 Treino vs. Inferência
🎓 Treinamento
Entrada xt (imagem ruidosa, conhecida) + t
Alvo ε (ruído que foi adicionado, conhecido)
Loss ‖ε − ε̂‖² — minimizar diferença de ruídos
Imagem Vem do dataset — sempre real, com x₀ conhecida
🚀 Inferência
Entrada xT ~ 𝒩(0, I) + t (decrementando)
Alvo nenhum — não há rótulo, só a rede prediz
Loss nenhuma — pesos fixos, só forward pass
Imagem Começa do ruído puro — x₀ nunca existiu antes
🌌 A rede só aprendeu os padrões de ruído das imagens do seu dataset. Na geração, a U-Net só consegue esculpir imagens que pertençam ao "universo" do que treinou — rostos se treinou com rostos, paisagens se treinou com paisagens. Não há como gerar algo além desse universo.
🔑 A mesma U-Net, com os mesmos pesos, faz treino e inferência. A diferença está apenas no dado de entrada: durante o treino, xt vem do dataset; na inferência, xT é ruído aleatório.
