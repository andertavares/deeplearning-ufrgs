Quando usar cada um?

🗜 Autoencoder
  • 📦 Compressão: reduzir dimensionalidade de dados
  • 🧹 Denoising: remover ruído de sinais e imagens
  • 🔎 Anomalia: detectar exemplos incomuns no dataset
  • 🧠 Representação: features para downstream tasks
  • ⚡ Rápido: treino estável e determinístico
🎨 GAN
  • 📸 Síntese: gerar imagens e áudio realistas
  • 🔄 Augmentation: ampliar dataset de treino
  • 🎭 Style transfer: mudar estilo visual de imagens
  • 🏥 Dados médicos: gerar amostras sintéticas balanceadas
  • ⚠️ Atenção: treino pode ser instável e delicado
