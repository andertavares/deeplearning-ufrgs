CNNs Precisam de Muitos Dados

Filtros não são pré-programados — são descobertos estatisticamente a partir de exemplos

Mensagem central
🎓
CNNs aprendem filtros automaticamente — mas isso exige muitos exemplos. Sem dados suficientes, a rede não consegue generalizar bem para imagens novas.
Por quê precisa de tantos dados?
🔀
Variedade de exemplos

A rede precisa ver exemplos do mesmo padrão em contextos diferentes para aprender o que é essencial — e o que é detalhe irrelevante.

🔄
Variações (rotação, iluminação, escala)

Um "X" levemente rotacionado ainda é um "X" para nós, mas para a rede é uma entrada diferente. Ela precisa ver todas essas variações para aprender invariância.

📊
Muitas amostras por classe

Com poucos exemplos, a rede "decora" o treinamento (overfitting) em vez de aprender padrões generalizáveis. Os filtros ficam ajustados apenas para aqueles poucos dados.

🔗

Isso vale diretamente para nosso exemplo: para aprender a detectar "X", a rede precisa ver muitas versões do X — com diferentes posições, variações de traço e orientação.

Variações do mesmo padrão
O mesmo "X" pode aparecer de formas ligeiramente diferentes. A rede precisa ver todas para generalizar.
Passe o mouse sobre cada variação para destacá-la ↑
Poucos dados vs. muitos dados
❌ Poucos dados
Filtros "decoram" os poucos exemplos
Não generaliza para imagens novas
Overfitting — erro baixo no treino, alto no teste
✅ Muitos dados
Filtros aprendem padrões essenciais
Generaliza para variações não vistas
Erro semelhante no treino e no teste
💡

Na prática, conjuntos como ImageNet têm 1,2 milhão de imagens de treinamento. Mesmo assim, técnicas como data augmentation são usadas para criar mais variações artificialmente.
