Feature Maps

O resultado de aplicar um filtro sobre toda a imagem — onde e com que intensidade o padrão foi detectado

Filtros ativos
🗺️
Um filtro → um feature map

Cada filtro gera um mapa que indica onde aquela característica foi encontrada e com que intensidade.

📦
Vários filtros → vários mapas

Camadas convolucionais têm dezenas ou centenas de filtros — cada um especializado em um padrão diferente.

🔥
Heatmap de ativações

Pixels mais brilhantes no mapa indicam maior ativação — o padrão foi encontrado com alta intensidade naquela região.

💡

Ligue e desligue cada filtro acima para ver como cada um detecta um padrão diferente na mesma imagem.

Mapas de features — imagem do X (9×9)
📐

Em CNNs, os mapas de features de uma camada são empilhados e passados como entrada para a próxima camada — não sobrepostos.
