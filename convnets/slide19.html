Como a Rede Aprende os Filtros

Backpropagation ajusta automaticamente todos os pesos — inclusive os filtros convolucionais

Até agora usamos filtros como se já soubéssemos quais padrões detectar. Mas, na prática, a rede aprende sozinha quais filtros usar — através de backpropagation.

Pesos ajustáveis em todos os lugares

Os filtros convolucionais são pesos da rede — assim como os pesos das camadas densas. Todos são ajustados no treinamento.

⬅️
Erro flui de trás para frente

O erro da saída se propaga pela rede no sentido contrário ao forward pass — da saída até os primeiros filtros.

🎯
Filtros emergem do dado

Os filtros que a rede aprende não são criados por humanos — eles surgem automaticamente a partir dos padrões presentes nos dados de treino.

🤔 Como a rede sabe o que ajustar?
O erro da saída indica o quanto cada parte da rede contribuiu para o erro — e isso inclui os filtros convolucionais.
