Conceitos-chave
🎯
Filtro = matriz pequena de pesos

Um filtro típico tem 3×3 ou 5×5 elementos — muito menor que a imagem de entrada.

🔎
Um filtro, um padrão

Cada filtro é especializado: um detecta diagonal ↘, outro ↗, outro o cruzamento central.

🔁
Mesmo filtro, toda a imagem

O mesmo conjunto de pesos desliza por cada posição da imagem — isso garante invariância de translação.

🗺️
Resultado = feature map

O resultado de aplicar o filtro em toda a imagem é um mapa de features — indica onde e com que intensidade o padrão aparece.

💡

Em CNNs, os pesos dos filtros não são definidos à mão — são aprendidos automaticamente via retropropagação durante o treino.
