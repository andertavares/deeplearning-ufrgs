Empilhando Blocos Convolucionais

Cada camada extrai padrões progressivamente mais complexos — ao final, a parte densa classifica

Arquitetura Multi-bloco
🖼️ Entrada H × W × C
↓
Bloco 1
⚙️ Conv 3×3 + bias
→
⚡ ReLU
→
🏊 MaxPool 2×2
padrões simples: arestas, diagonais…
↓
Bloco 2
⚙️ Conv 3×3 + bias
→
⚡ ReLU
→
🏊 MaxPool 2×2
combinações complexas: partes, formas…
↓
📐 Flatten → vetor 1D
→
🧠 Dense + ReLU
→
🎯 Saída Softmax
💡

O padrão Conv → ReLU → MaxPool pode ser repetido quantas vezes for necessário, com novos filtros em cada bloco.

Hierarquia de Features
📏
Bloco 1 — Padrões Primitivos

Detecta arestas, linhas e diagonais. Os filtros respondem a variações locais de intensidade na imagem.

🔷
Bloco 2 — Estruturas Complexas

Combina padrões primitivos em formas geométricas e partes de objetos, usando os feature maps do bloco anterior como entrada.

📐
Flatten — Representação Compacta

Transforma os feature maps 2D em um vetor 1D — a "descrição" aprendida pela rede, pronta para classificação.

🧠
Parte Densa — Classificação

Camadas fully-connected combinam as features para produzir a pontuação de cada classe.

🎓
Fluxo básico da CNN:
entrada → Conv+ReLU+Pool → … → Flatten → Dense → saída.
Novos filtros aprendem novos padrões em cada bloco.
