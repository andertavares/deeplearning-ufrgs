🔷 Multi-Head Attention
Mistura informação entre tokens: cada posição pode "olhar" para todas as outras. O resultado A tem as mesmas dimensões de X (d_model = 2 neste exemplo), mas integra contexto de todas as posições via atenção multi-cabeça.
A = MultiHead(Q, K, V)    [n_tokens × d_model]

➕ Add & Norm — 1ª conexão residual
Residual (Add): soma A com a entrada original X. Isso preserva o sinal original e garante que o gradiente possa fluir diretamente pela camada.

LayerNorm: normaliza cada vetor de token individualmente. Para o token i, calcula a média μi e o desvio padrão σi ao longo das dmodel dimensões daquele único vetor — não ao longo do batch. Resultado: z̃[i] = (z[i] − μᵢ) / σᵢ. Cada linha da matriz é normalizada de forma independente das demais.
A' = LayerNorm( A + X )

🔶 Feed-Forward Network (FFN)
Processa cada token de forma independente — sem misturar informação entre posições. É uma MLP de 2 camadas: expansão com ReLU, depois projeção de volta para d_model. Dimensões: W₁ ∈ ℝd × d_ff, W₂ ∈ ℝd_ff × d, H ∈ ℝn × d. Na prática d_ff = 4 × d (ex.: d=512 → d_ff=2048).
FFN(z) = ReLU(W₁·z + b₁)·W₂ + b₂

(2021) mostram que as linhas de W₂ funcionam como "memórias associativas": cada neurônio oculto ativa para certos padrões de entrada e projeta de volta um vetor de saída — como uma tabela de consulta aprendida.
➕ Add & Norm — 2ª conexão residual
Mesma estrutura da primeira: soma a saída do FFN com a entrada A', depois aplica LayerNorm. Garante que o gradiente flua diretamente pelo caminho de skip, mesmo se o FFN não contribuir com informação nova.
H = LayerNorm( FFN(A') + A' )

📤 Saída da Camada do Encoder — matriz H
A matriz H é a saída de uma camada completa do encoder. Cada linha é a representação refinada de um token após atenção + FFN + normalização. Em um Transformer com N camadas, H alimenta a próxima camada como novo X.
H = LayerNorm( F + A' )    ∈ ℝn × d

🌊 Residuais

Permitem treinar redes muito profundas.

Encoder Layer completa
A = MultiHead(Q,K,V)
A' = LayerNorm(A + X)
F = FFN(A')
H = LayerNorm(F + A')  → classificador
🧠

A atenção mistura informação entre tokens. Depois, o feed-forward refina cada representação individualmente, e as conexões residuais ajudam a preservar e estabilizar o fluxo de informação — permitindo treinar redes com dezenas de camadas.
