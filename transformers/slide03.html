Embeddings Estáticos

IDs de tokens — cada palavra é mapeada para um índice inteiro no vocabulário do modelo. Ex.: "Ela" → 42, "saiu" → 98, "só" → 17. Esses IDs são a entrada real da rede: números, não texto.
Modelos como Word2Vec (2013) e GloVe (2014) aprendem vetores densos para cada palavra a partir de co-ocorrências em grandes corpora. Cada palavra recebe um único vetor, independente do contexto.
