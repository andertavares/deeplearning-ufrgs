Message Passing

Bloco 2 — O coração das GNNs

1
Gather
📥
Coleta as features dos nós vizinhos
Cada nó reúne as representações de todos os seus vizinhos para processamento.
M_v = { h_u : u ∈ N(v) }
2
Aggregate
🔀
Combina as mensagens recebidas
Funções permutation-invariant: soma, média, máximo.
m_v = AGG({ M_u : u ∈ N(v) })
3
Update
🔄
Atualiza o embedding do nó central
Combina a representação atual com a mensagem agregada via rede neural.
h_v' = σ(W · [h_v ‖ m_v])
Animação ao vivo — message passing em um nó
