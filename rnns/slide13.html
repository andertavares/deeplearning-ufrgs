📋 Passos do BPTT

  • 1Forward: h₁ = φ(U·x₁ + bₕ)
  • 2Forward: h₂ = φ(U·x₂ + V·h₁ + bₕ)
  • 3Forward: h₃ = φ(U·x₃ + V·h₂ + bₕ)
  • 4Forward: h₄, o₄ = ψ(W·h₄), L = ℓ(o₄, ŷ)
  • 5Backward: ∂L/∂h₄ via ∂L/∂o₄ · ∂o₄/∂h₄
  • 6Backward: ∂L/∂h₃ = ∂L/∂h₄ · Vᵀ·φ′(·)
  • 7Backward: ∂L/∂h₂ = ∂L/∂h₃ · Vᵀ·φ′(·)
  • 8Backward: ∂L/∂h₁ = ∂L/∂h₂ · Vᵀ·φ′(·)
🔀 Em many-to-one apenas h₄ recebe gradiente direto de L. Os estados anteriores recebem gradiente apenas via conexões recorrentes (Vᵀ).
