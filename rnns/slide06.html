Dados Sequenciais: Definição e Exemplos

Sequência = coleção ordenada — a ordem carrega o significado

📋 O Que é um Dado Sequencial?

Todo dado em que a ordem dos elementos é relevante. Em vez de uma entrada única x, temos:
x₁, x₂, x₃, …, xₜ
Sequência
Elementos ordenados
Intervalo não precisa ser uniforme
Ex.: palavras, ações, DNA
VS
Série Temporal
Indexada por instantes de tempo
Intervalo geralmente uniforme
Ex.: ECG, preços, temperatura
Toda série temporal é uma sequência — mas nem toda sequência é uma série temporal.

O passo temporal importa. Cada xₜ não vive sozinho — ele é parte de um contexto em evolução. O passo temporal pode mudar a interpretação do próximo elemento.
